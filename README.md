# Goa Global Academy of Higher Education

Goa Global Academy of Higher Education is a distance and online learning web application providing UGC & AIU recognized Undergraduate, Postgraduate, Professional Diploma, and 10th & 12th Open Board programs.

## Features
- **Hero Portal**: Glassmorphic enquiry card, course lookup, and stats counter.
- **Course Finder & Fee Estimator**: Interactive eligibility calculator for degree courses.
- **3D Flip Cards**: Interactive feature cards showcasing accreditations and learning benefits.
- **Holographic Cards**: Cybernetic holographic hover light sweep on course cards.
- **Floating Contact Widget**: Direct WhatsApp chat and telephone assistance.
- **Responsive Layout**: Designed with HTML5, Vanilla CSS, Bootstrap, and Laravel framework.

## Tech Stack
- **Backend**: Laravel PHP Framework
- **Frontend**: Blade Templates, Bootstrap 5, FontAwesome 6, Custom CSS Animations
- **Database**: MySQL

## Setup & Running Locally
```bash
composer install
npm install
php artisan key:generate
php artisan serve
```
